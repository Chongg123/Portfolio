# Kurt Christian Espero — Interactive Portfolio

A futuristic, high-performance personal portfolio website built with vanilla HTML5, CSS3, and JavaScript featuring an **Aura & Cyber-Minimalist** aesthetic.

![Kurt Christian Espero Portfolio Preview](assets/avatar.jpg)

---

## 🌟 Features

- **Personal Narrative & Vibe Coding Creed**: Highlights BSIT background, natural language prompt engineering, and multi-platform development.
- **3D Interactive Particle Constellation Canvas**: HTML5 Canvas with 3D projection, depth sorting, and cursor repulsion.
- **Perspective 3D Tilt Cards**: Fluid 3D physics with mouse-following radial spotlight shaders.
- **Zero-Dependency Web Audio Synthesizer**: Custom acoustic sci-fi micro-interactions (blips, whooshes, chords).
- **Command Palette (`Ctrl + K`)**: Instant HUD launcher with theme switcher, sound toggle, section jump, and CV download.
- **Dynamic Color Themes**: 4 live themes (*Cyber Aura*, *Matrix Emerald*, *Sunset Ruby*, *Electric Indigo*).
- **Featured Project Case Studies**:
  - 📚 **Library Management System (`UniLib`)** — Book cataloging, circulation telemetry, and barcode integration.
  - ⚡ **Electricity Billing System (`ApexGrid`)** — Kilowatt-hour metering, automated tariff tiers, and PDF invoicing.
  - 🤝 **SKLink** — Youth governance & community portal for the Sangguniang Kabataan.
- **Dual-Mode Contact Uplink**: Friendly GUI form + interactive simulated Dev Terminal console.

## 🚀 Getting Started

### 1. Run Locally
Open `portfolio.html` directly in any modern web browser:
```bash
# Or start a local static server
python -m http.server 3000
```
Then visit `http://localhost:3000/portfolio.html`.
